# Доска техничек

Небольшой веб-инструмент для планирования недельного графика техничек (собеседований/дежурств) без привязки к конкретной команде — просто открываете файл в браузере и вписываете своих людей.

Работает как одна HTML-страница без бэкенда: открыл файл — и доска готова. Данные хранятся в общем (shared) хранилище, поэтому все, кто открывает эту доску, видят одни и те же актуальные данные и правки друг друга в реальном времени.

## Зачем это нужно

Каждую неделю нужно распределить между несколькими людьми дежурства/техничков двух типов (короткие и длинные), учитывая:
- у кого какие окна свободного времени;
- кто обязательно должен быть поставлен на этой неделе;
- кто в отпуске и недоступен;
- кого с кем удобнее ставить в пару по пересечению свободного времени;
- сколько техничек уже набрано и сколько нужно по плану.

Раньше это считалось вручную в переписке/таблицах — доска автоматизирует всю рутину.

## Основные возможности

**Чек-лист на неделю**
Список людей с отметками «точно ставим», «в отпуске» и полем «ходит в паре с» — быстрый обзор перед распределением.

**Слоты и лимиты**
Для каждого человека — окна свободного времени, счётчики техничек двух типов (клик по чипу переключает 0 → 1 → 2 → 3), автоматический подсчёт «всего / лимит» с подсветкой превышения.

**Загрузка окон времени двумя способами**
- вручную текстом (`10:00-13:00, 15:00-18:00`);
- автоматически — загрузкой CSV-выгрузки календаря (Outlook) или скриншота недельной сетки календаря (доска сама распознаёт занятые/свободные ячейки по цвету и заполняет окна).

**Подбор пар**
Отдельная панель предлагает, кого с кем ставить, исходя из пересечения их свободного времени.

**Подстраховка**
Отдельная роль «третий участник» (имя вводится вручную), который присутствует на всех техничках и не считается в общий лимит.

**Счётчик плана**
Указываете, сколько техничек нужно набрать за неделю — наверху страницы прогресс-бар показывает, сколько уже набрано.

**Подсветка незаполненных**
Люди, которые ещё не указали своё свободное время, визуально выделяются в таблице.

**История недель**
При старте новой недели («Новая неделя») текущие итоги (кто сколько отработал, сводка, план) сохраняются в архив, а счётчики обнуляются — можно свериться с прошлыми неделями в любой момент.

**Сводка неделей текстом**
Свободное поле для заметок/итогового решения по неделе — чтобы скопировать и отправить в чат.

## Как пользоваться

1. Откройте `calendar.html` в браузере.
2. Добавьте людей через поле «Имя нового интервьюера» внизу списка.
3. Впишите окна свободного времени вручную, или загрузите CSV/скриншот календаря.
4. Отметьте обязательных и отпускников в чек-листе.
5. Кликайте по чипам №1/№2, чтобы отметить, сколько техничек уже назначено каждому.
6. Проверьте подсказки «Кого с кем ставить».
7. В конце недели нажмите «Новая неделя» — итоги уйдут в архив, счётчики обнулятся.

## Технически

- Чистый HTML/CSS/JS, без сборки и зависимостей.
- Хранение данных — через встроенное key-value хранилище (`window.storage`), общее для всех, кто открывает страницу.
- Шрифты: Space Grotesk, Inter, JetBrains Mono (Google Fonts).
